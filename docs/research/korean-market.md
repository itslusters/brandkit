Source-backed notes on the Korean logo/branding market, what customers
actually complain about, and where Atriium has real differentiation.
This is the reference doc for landing / pricing / company copy and for

## 1. Price tiers

From [studiomorning.kr 2026 pricing guide](https://studiomorning.kr/logo-design-cost/):

| 가격대 | 포함 | 한계 |
|--------|------|------|
| **0~5만원** | Looka / Canva AI 툴 | "템플릿 기반이라 다른 브랜드와 비슷함" |
| **5~15만원** | 빠른 프리랜서 | 컨셉 1-2, 기본 수정, 벡터 제공 제한적 |
| **20~50만원** | 경력 프리랜서 | 컨셉 2-3, 수정 3회 이상, 전략 상담 시작 |
| **50~150만원** | 브랜딩 스튜디오 | 로고 + 명함 + 기본 가이드, 브랜드 기준 문서 |
| **150만원+** | 에이전시 풀패키지 | CI/BI, 20~50쪽 가이드, 사이니지/패키징 |

크몽 평균 10~12만원, 라우드소싱 컨테스트 20~50만원. [숨고 통계](https://soomgo.com/prices/%EB%A1%9C%EA%B3%A0-%EB%94%94%EC%9E%90%EC%9D%B8): 평균 10만원 (최저 5만, 최고 30만).

## 2. 실제 페인 — 데이터 기반

### ✅ 확인된 페인

1. **벡터 파일 미제공**
   출처: studiomorning.kr
   원문: "벡터 파일 없이 JPG/PNG만 받으면 나중에 완전 재작업 비용 발생"
   → Atriium 제안 가치: Essentials 이상 SVG 기본 제공

2. **6~12개월 후 리브랜드 비용**
   출처: studiomorning.kr
   원문: "저렴한 초기 투자가 방향 바뀌면 오히려 더 비싸짐"
   → Atriium 제안 가치: Brand Memory로 DNA 유지한 채 진화

3. **플랫폼별 이미지 재가공 지옥**
   출처: [draph.art 스마트스토어 블로그](https://draph.art/blog/insights/dont_run_smartstore_alone)
   원문: "각 플랫폼마다 요구하는 이미지 규격이 다르고 상세페이지 구성도 달라요"
   → Atriium 제안 가치: 멀티채널 mockup 자동 생성 (Pro/Studio)

4. **저작권 양도 불명확**
   출처: studiomorning.kr
   원문: "지불해도 권리가 자동으로 이전되는 건 아님"
   → Atriium 제안 가치: 생성 즉시 상업적 사용 가능 (terms에 명시)

5. **AI 툴 "템플릿 티"**
   출처: studiomorning.kr + Looka 리뷰
   원문: "다른 브랜드와 비슷한 로고 나옴"
   → Atriium 제안 가치: 3 variant + 무제한 refine + 디자이너 핸드오프

6. **스토어명 1회만 변경 가능 (네이버)**
   출처: [토스페이먼츠 블로그](https://www.tosspayments.com/blog/articles/semo-45)
   원문: "URL 영구 고정, 초기 네이밍을 신중히 해야"
   → Atriium 제안 가치: AI 네이밍 3~5개 후보 + A/B poll로 검증

### ❌ 내가 틀렸던 가정

- **"크몽 기다림이 페인"** — 리뷰 대체로 긍정적. 수정 정책 명확 (50% 환불 룰 존재). 시간 자체는 불만 아님.
- **"라우드소싱 의뢰자가 피곤"** — 2021년 라우드마켓 1:1 모델 도입 후 개선. 의뢰자 불만 데이터 제한적.
- **"AI 로고 툴이 한국어 미지원"** — [Canva](https://www.canva.com/ai-logo-generator/), [Looka](https://www.toolify.ai/ko/tool/looka) 모두 한국어 UI/지원. 언어 자체는 차별점 아님.

## 3. 경쟁자

| 서비스 | 강점 | 약점 |
|--------|------|------|
| **크몽** (kmong) | 후기 많음, 수정 정책, 실제 사람 | 시안 품질 변동, 저작권 별도, 벡터 별도 |
| **라우드소싱** (loud.kr) | 시안 다수 선택 가능 | 컨테스트 피로, 의사결정 비용 높음 |
| **Canva 한국어** | 무료, 친숙, 한국어 완벽 | 템플릿 느낌, 브랜드 일관성 약함, 벡터 유료 |
| **Looka** | AI 특화, 한국어 지원 | 결과물 "다른 브랜드와 비슷", 한글 타이포 약함 |
| **네임릭스 / 네이미** | 한글 네이밍 강점 | 네이밍만, 로고/브랜드 시스템 없음 |
| **미리캔버스** | 무료, 네이버 셀러에 친숙 | DIY 편집 툴, AI 자동화 아님 |

**Atriium의 진짜 경쟁자는 Canva와 Looka.** 크몽/라우드소싱은 다른 시장 (done-for-you).

## 4. 타겟 페르소나 (데이터 기반)

### 🎯 Primary: "멀티채널 일꾼"

**누구**: 스마트스토어 셀러, 쿠팡 파트너, 인스타 쇼핑몰, 1인 유튜버, 솔로 앱 개발자, 뉴스레터 작성자
**매주 필요**: 썸네일, 배너, 상세페이지 헤더, 소셜 포스트
**현재 해결**: 미리캔버스 DIY + 크몽 일회성 로고 + Canva
**Atriium이 꽂히는 각**: 브랜드 한번 세팅하면 모든 채널 자동 변환, 매달 월 $19

### ❌ Secondary 아님 (Atriium에 안 맞는 타겟)

- **일회성 로고 구매자** (창업 전 CI만 필요한 사람): 가격 민감, 평생 안 돌아옴 → Canva 5만원에 만족
- **대기업 리브랜딩**: 에이전시 영역, Atriium 스코프 밖
- **법적 상표 등록 필요한 케이스**: 디자인 별도, 등록 프로세스 복잡

## 5. 포지셔닝 결론

### 🎤 Do — 데이터 기반 메시지
- "벡터 SVG, 저작권, 브랜드 가이드 전부 한번에"
- "한 브랜드, 모든 채널 — 로고부터 썸네일까지"
- "3개월 뒤에도 같은 DNA로 진화"
- "필요하면 진짜 디자이너가 손봅니다"

### 🚫 Don't — 약점 공격형 / 촌스러운 카피
- ❌ "크몽에서 3일 기다리지 마세요"
- ❌ "AI로 10분만에" (Canva 동일 주장)
- ❌ "저렴하게" (가격 레이스는 진다)
- ❌ "당신만의 특별한 브랜드" (추상적, 증거 0)

## 6. 한국어 시장 진입 단계

### Phase 1 (이번 달) — 근거 기반 카피 + 웨이팅
- 랜딩/pricing/company 페이지 카피 데이터 기반으로 재작성 (이 문서 인용)
- 웨이팅 리스트 랜딩 (한국어 A/B)
- Twitter/Threads 계정 개설 — build-in-public

### Phase 2 (다음 달) — 한국어 UI + KRW 가격
- next-intl 설정, UI 문자열 토큰화
- Claude 한글 네이밍 모드 (브리프 입력이 한글이면 한글 후보 생성)
- Pricing ₩ 병기

### Phase 3 (3개월 내) — 한글 로고 베타
- Satori + Pretendard/Spoqa Han Sans Neo로 wordmark 타입 한글 렌더링
- symbol+text / emblem은 Recraft 영문만 (Recraft V3 한글 쓸 때 깨짐)
- 한글 로고 베타 명시적 표시

### Phase 4 (6개월 내) — 한국 시장 확장
- 한국 SMB 특화 목업 (스마트스토어 썸네일, 카카오톡 프로필, 당근마켓 헤더)
- 한국 스타일팩 추가 (한식/전통, K-뷰티, 네이버 감성)
- KR 결제 (토스/카카오페이 — iOS는 계속 IAP)
